# ASCII Art Web by Yryszhan

## Description

ASCII Art Web — это веб-приложение на Go, позволяющее генерировать ASCII-арт из введённого текста с использованием трёх стилей баннеров: shadow, standard и thinkertoy. Пользователь вводит текст, выбирает стиль и получает результат прямо на веб-странице.

## Authors

- YRYSZHAN and NURASYL

## Usage: How to Run

1. Установите Go (https://golang.org/dl/).
2. Клонируйте репозиторий и перейдите в папку проекта.
3. Убедитесь, что в папке `banners/` лежат файлы `standard.txt`, `shadow.txt`, `thinkertoy.txt`.
4. Запустите сервер командой:
   ```bash
   go run main.go
   ```
5. Браузер откроется автоматически, либо перейдите на [http://localhost:8080](http://localhost:8080).

## Implementation details: algorithm

- Сервер реализован на стандартной библиотеке Go.
- Для парсинга баннеров используется формат: каждая буква/символ начинается с `[X]`, далее идут строки ASCII-арта.
- Веб-интерфейс реализован через HTML-шаблоны (Go templates).
- Поддерживаются GET (главная страница) и POST (генерация ASCII-арта) запросы.
- Корректно обрабатываются ошибки (неверный запрос, отсутствие баннера, ошибки сервера).

## Пример использования

1. Введите текст в поле.
2. Выберите стиль баннера.
3. Нажмите "Generate ASCII Art".
4. Получите результат на той же странице.
